# 询价转让投资备忘录 Workflow（A股）

一个用 [Claude Code](https://claude.com/claude-code) 自动化生成 A 股**询价转让**投资备忘录的 workflow。

输入公司名+股票代码（+可选的卖方底价、Wind数据、研报PDF），自动产出一份 5 页以内的结构化 .docx 备忘录，覆盖估值、市场表现、季度业绩、股东资金面、舆情面、公司财务、亮点风险。

## 适用场景

- 创业板/科创板**询价转让**询价过程中的快速估值判断
- 卖方底价 vs 机制底价（20日均价×70%）的折扣率分析
- 转让价档位（卖方底价 / 折价15% / 折价30%）的P/E、EV/EBITDA推算
- 多平台舆情面分析（股吧 + 韭研公社 + 财富号 + 互动易）

## 如何使用

1. 把本仓库的 `CLAUDE.md` 拷贝到你自己的项目目录
2. 在该目录下安装并启动 [Claude Code](https://claude.com/claude-code)
3. 准备 raw data（推荐结构）：
   ```
   project/
   ├── CLAUDE.md
   └── Data/
       ├── [近三年年报PDF]
       ├── [最新季报/半年报PDF]
       ├── [日度估值/股价/CSC可比数据 Excel]
       └── [Wind consensus截图、rating截图]
   ```
4. 在 Claude Code 中输入：`公司名 股票代码 [卖方底价（可选）]`
   - 例：`华海诚科 688535 22.50`
   - 例：`华海诚科 688535`（无卖方底价时自动计算机制底价 = 20日均价×70%）
5. Claude 会按三阶段流程执行：
   - **阶段一**：数据采集（年报PDF解析、Wind截图提取、舆情面多源采集）
   - **阶段1.5**：生成 `data.json` 数据中间层 + 自动化校验
   - **阶段二**：生成 .docx 备忘录

## 核心设计

### 1. 数据来源分层

| 类别 | 来源 | 规则 |
|---|---|---|
| 财务数据 | 公司年报/季报原文PDF | 一手公告唯一来源，不允许从研报/新闻凑数 |
| 市场/交易数据 | 财经网站（北向、融资融券、股价等） | 可以从财经网站获取 |
| 舆情/情绪数据 | 股吧、韭研公社、财富号、互动易 | 严禁进入财务表，仅作情绪面参考 |

### 2. 双底价机制

- **卖方底价**（用户提供）：询价转让公告中的指定底价
- **机制底价**（Claude自动算）：过去20交易日均价 × 70%，作为法定下限

两者按场景分别展示，避免估值表口径混乱。

### 3. 数据中间层（data.json）

财务数字由 Python 脚本统一计算并输出 JSON。文档生成代码（JS）从 JSON 读取，**禁止硬编码任何财务数字**——杜绝手工复制粘贴错误。

### 4. 自动化校验

阶段1.5 包含：
- 毛利率口径一致性（三年同口径）
- EBITDA 公式一致性（营业利润 + D&A + 利息支出）
- P/E 口径分离（FY(N)A 用年报EPS，FY(N+1)E 用consensus）
- 三年趋势合理性检查

### 5. 输出格式

- Word .docx，5 页以内
- Calibri 字体，7-8pt 正文
- 4 模块：A 估值 / B 季度+News Run+舆情 / C 股东资金面 / D 公司+财务+亮点风险
- 投资亮点和风险用 3×3 表格，强制压缩
