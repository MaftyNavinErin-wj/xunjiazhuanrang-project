# 简化投资推荐 Workflow

本 workflow 用于在已生成询价转让 memo 之后，进一步基于 memo、同事报告、公开信息和用户额外材料，生成一张可直接用于投资讨论的简化推荐表。

它不是替代原始投资备忘录，而是把多份材料压缩成“是否值得下手、核心理由、估值位置、关键验证点”的决策版输出。

## 适用场景

- 多个询价转让项目横向比较。
- 用户已经提供 memo PDF、个股详情报告、研究报告、Wind/CSC 数据、券商材料或额外观点。
- 需要从完整报告中提炼投资排序，而不是再生成一份长 memo。
- A 股情绪驱动较强，不能只按静态基本面和底价折扣判断。

## 输入优先级

1. 用户提供的 memo / 报告 / Excel / 截图。
2. 公司公告、年报、季报、业绩快报等一手公开披露。
3. Wind/CSC/Bloomberg 等市场数据或用户给定导出。
4. 公开新闻、财经网站、交易所公告、互动易、股吧/社媒情绪。
5. 用户额外判断、同事观点、内部口径。

财务数字优先使用公司公告和用户材料。公开新闻主要用于交叉验证事件、股东减持、询价转让进展和市场情绪，不作为财务主数据来源。

## 核心原则

### 1. 不把底价当成交价锚

询价转让底价只是卖方保留价，不是最终成交价预测。

- 热票、有共识的票，最终成交价可能显著高于底价，折扣偏低。
- 冷票、分歧大的票，即使底价折扣深，也可能只是风险补偿。
- 判断重点应从“底价折扣多深”转向“最终成交价附近的风险收益是否成立”。

输出中可以列示底价对应估值，但结论不能单纯因为底价深就看多，也不能单纯因为底价浅就否定。

### 2. 同时看基本面和情绪持续性

A 股询价转让判断需要两套框架合并：

- 基本面：收入、利润、毛利率、现金流、ROE、客户集中度、股东减持、FY26/27E P/E。
- 情绪面：AI、半导体、国产替代、机器人、重组、华为链、光刻机链、卫星互联网等当前市场主线。

结论必须回答：这个故事能否撑过 6 个月锁定期，尤其能否撑过下一次中报/季报验证。

### 3. 重视中报验证

对于锁定期内会遇到中报或季报的标的，必须标明验证压力：

- Q1 已经证伪利润质量的，重点看 Q2/中报毛利率和净利润能否修复。
- 主题弹性强但利润弱的，需要说明“会遇到中报考验”。
- 基本面强且 Q1 完成度高的，可以说明“中报不容易被证伪”。
- 完全依赖重组或事件的，需要说明“现有主业无法兜底”。

### 4. 用最 punchy 的论点

每家公司只保留 1-2 个最强论点，必须有数字或事实支撑。避免泛泛而谈。

好的论点示例：

- “基本面非常强，中报大概率没问题：2026Q1 归母 +61.3%，毛利率 69.8%。”
- “题材性感，但 Q1 有伤：2026Q1 净利润仅 160 万，同比 -92.8%，毛利率降 11.7pct。”
- “基本面一坨屎，完全看重组：2026Q1 营收 300 万，同比 -95.7%，现有主业无法支撑市值。”

不好的论点示例：

- “公司质地不错。”
- “估值较高但未来可期。”
- “题材比较多。”

## 操作步骤

### Step 1. 文件盘点和文本化

扫描 `projects/`，确认每家公司有哪些材料：

- 询价转让 memo。
- 同事生成的个股详情报告。
- 研究报告。
- Excel、截图、用户补充材料。

PDF 先用 `pdftotext -layout -enc UTF-8` 转为 `.txt`，再检索关键字段。

### Step 2. 抽取核心字段

每家公司至少抽取：

- 公司代码和名称。
- 当前价、底价、底价对应折扣，如适用。
- FY26E P/E、FY27E P/E，如适用。
- 底价对应 FY26E/FY27E P/E，如适用。
- FY2025 收入、净利润、增长。
- 2026Q1 收入、净利润、毛利率、同比变化。
- 关键主题标签：AI、半导体、国产替代、机器人、华为链、重组等。
- 关键风险：毛利率下滑、亏损、股东减持、客户集中、无机构覆盖、重组不确定。

### Step 3. 公开信息交叉验证

对以下事项做公开信息核对：

- 询价转让公告和规模。
- 最新年报、季报、业绩快报核心数字。
- 重大资产重组进展。
- 重要股东减持、质押、解禁。
- 主线行情和板块情绪，如半导体 AI 国产替代是否仍活跃。

如公开信息与用户材料冲突，优先标明冲突，并说明使用哪个口径。

### Step 4. 给出结论和排序

每家公司给出简洁结论，不要只写“买/不买”，而要写清楚它属于哪类机会：

- 核心主线资产。
- 进攻型情绪票。
- 可看但不是核心主线。
- 故事强但利润证伪。
- 折价事件票。
- 重组期权。
- 明确回避。

排序需要体现综合判断，而不是单一估值低高。

### Step 5. 输出推荐表

默认输出四列：

| 公司 | 结论 | P/E | 最强论点 |
|---|---|---:|---|

格式要求：

- row 与 row 之间插入一个空白行，提升可读性。
- 结论写 1-2 句，说明是否值得参与以及主要条件/风险。
- P/E 列列示 FY26E、FY27E；如适用，列示底价对应 FY26E/FY27E。
- 无有效预测时写“无有效机构预测”或“无机构预测”，不要硬凑。
- 最强论点列只写 1-2 个 punchy theme，并用数字支撑。
- 表后给最终排序。

## 输出模板

```markdown
| 公司 | 结论 | P/E | 最强论点 |
|---|---|---:|---|
| **公司A** | **可以买，核心主线资产。** 基本面兑现强，锁定期内最不容易被中报证伪。 | FY26E **xx.xx**；FY27E **xx.xx**；底价对应 FY26E **xx.xx** / FY27E **xx.xx** | **基本面非常强，中报大概率没问题。** FY2025 营收 **xx 亿 +xx%**，净利润 **xx 亿 +xx%**；2026Q1 营收 **xx 亿 +xx%**，净利润 **xx 亿 +xx%**。 |
|  |  |  |  |
| **公司B** | **可做进攻票，但会遇到中报考验。** 题材很强，但 Q1 利润质量需要 Q2 修复。 | FY26E **xx.xx**；FY27E **xx.xx**；底价对应 FY26E **xx.xx** / FY27E **xx.xx** | **题材性感，但 Q1 有伤。** FY2025 业绩高增；但 2026Q1 净利润 **xx 万，同比 -xx%**，毛利率降 **xxpct**。 |
```

## 判断标签库

可复用的结论标签：

- 最硬主线资产。
- 进攻型情绪票。
- 会遇到中报考验。
- 不是本轮最核心主线。
- 故事强但利润方向差。
- 折价事件，不是主线票。
- 基本面一坨屎，完全看重组。
- 现有主业无法兜底。
- 质量好但成交价不便宜。
- 深折价只是风险补偿。

## 本次样例排序

基于 2026-05-23 已处理的六家公司样例：

1. 澜起科技：最硬 AI 半导体主线资产，基本面和情绪共振。
2. 灿勤科技：进攻型情绪票，题材性感但 Q1 有伤。
3. 伟创电气：机器人逻辑可交易，但不是 AI 半导体核心票。
4. 茂莱光学：半导体光学故事强，但利润方向太差。
5. 超达装备：折价事件，不是主线票。
6. 晶升股份：基本面一坨屎，完全看重组。

这个样例只是 workflow 参考，不应作为未来项目的固定排序模板。

## 质量检查

输出前检查：

- 是否同时读取了用户 memo 和新增报告。
- 是否补做公开信息交叉验证。
- 是否降低了底价权重，避免“底价深 = 便宜”的机械判断。
- 是否列出 FY26E/FY27E P/E，如适用。
- 是否明确中报/季报验证压力。
- 是否每家公司只有 1-2 个最强论点。
- 是否每个强论点都有数字或事实支撑。
- 是否避免仓位建议，除非用户明确要求。
- 是否说明排序逻辑，而不是只给表格。
